# Бот «Карантин 311»

Гость подаёт заявку → 3 админа голосуют → при 2 одобрениях гость получает код-пропуск.

## Запуск
1. Создай бота у @BotFather, возьми токен.
2. Каждый из трёх админов должен написать боту `/start` (иначе бот не сможет им писать). Свой id — у @userinfobot.
3. ```bash
   cp .env.example .env   # впиши токен и ADMINS
   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
   .venv/bin/python bot.py
   ```

## Деплой на Render (бесплатно)
Локально бот работает через опрос и SQLite. На Render он сам переключается на веб-хук (по `RENDER_EXTERNAL_URL`) и Postgres (по `DATABASE_URL`).
1. Бесплатная база: neon.tech → создать проект → скопировать connection string (`postgresql://…`).
2. Залить папку на GitHub (`.env` в `.gitignore`, токен в репозиторий попадать не должен).
3. Render → New → Blueprint → выбрать репозиторий. Заполнить `BOT_TOKEN`, `ADMINS`, `DATABASE_URL`.
4. UptimeRobot: HTTP-монитор на `https://<имя>.onrender.com/health` раз в 5 минут, иначе бесплатный сервис засыпает.
5. Локального бота остановить: два экземпляра с одним токеном мешают друг другу.

## Гость
`/request` — заявка (тема → день → время → сколько человек), `/my` — статусы, коды и отмена.

## Админы
`/today` визиты на сегодня · `/check 1234` проверить код у двери · `/pause` `/resume` стоп/старт приёма · `/block ID` `/unblock ID`.

## Правила и фишки
- 2 одобрения → одобрено; 2 отказа (когда 2 одобрений уже не набрать) → отклонено. Голос менять нельзя.
- Одна активная заявка на человека, лимит 2 заявки в день, подача минимум за 30 мин, часы визитов 10:00–22:00 (всё в `.env`).
- Неразобранные заявки сами «протухают» после времени визита.
- Напоминание гостю и админам за 15 минут до визита.
